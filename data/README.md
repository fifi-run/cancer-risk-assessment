# Dataset source and handling

The supplied group coursework archive contained a file named cancer patient data sets.csv with a Patient Id field and health-related variables. The exact upstream URL, dataset version, licence and de-identification status were not established from the supplied materials.

The raw dataset is therefore not redistributed in this repository. Before adding any copy, verify the source terms, permission to redistribute, and whether the data are appropriately de-identified.

If you have an authorised copy, place it at data/cancer_risk_dataset.csv for the notebook workflow.
